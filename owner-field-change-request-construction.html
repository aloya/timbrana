Project scenario · Owner request

The owner asks for a field change during a walkthrough. Where should it go?

An owner request can start as a casual field conversation but quickly affect scope, price, schedule and responsibility. The path should preserve the original request without treating the conversation itself as approval.

Construction project scenarioUpdated September 28, 2026

Capture the original request

Record what the owner asked for in plain language, including location and any supporting photo. If the request contains multiple independent decisions, separate them so each can move at its own pace.

Separate the owner-facing question from internal work

The owner should see the request, clarifications and decisions that involve them. Internal discussion about trade responsibility, cost development or sequencing should remain inside the project team.

Determine whether pricing is required

If the request changes contracted scope or cost, move it into a change-order path. The project manager can determine which trade partners need pricing, add adjustments or markup and prepare the owner-facing proposal.

Do not confuse request with approval

A field conversation such as “can we move this railing?” is not automatically authorization to proceed. The status should make clear whether the team is clarifying, pricing, awaiting an owner decision or released to perform the work.

Close the loop

Once the owner decides, keep the decision connected to the original request. If accepted, the work can move into execution. If declined, the project still retains a clear record of what was asked and how it was resolved.

The goal is one understandable project thread.

Keep the original condition or communication, the current responsibility and the next action connected instead of recreating the same item in multiple places.

How this fits Timbrana

Timbrana is designed so everyday project activity can move into the workflow that owns the next step while preserving where the item came from. That can mean an issue, scheduled event, owner question, RFI, change order or personal follow-up depending on what the project actually needs.
